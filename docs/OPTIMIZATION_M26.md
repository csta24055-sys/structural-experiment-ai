# 実際の支払総額で比べる（M26）

M26（台帳 P143〜P145）: 技術的な効率ではなく、成果と品質を保ったまま**実際に支払う総額**を最も安くする。
3大原則（①成果を減らさない ②品質を下げない ③今の方式に固執しない）は維持する。
記号: [実測] [計算]（公式料金×量）[推定]。金額は全 9 資料、1 USD = 155 円。

## 1. 何に実際に支払うか（この利用者の環境）
| 費用 | 実際の支払い | 根拠 |
|---|---|---|
| Anthropic の API（従量課金） | 使った分だけ | 公式料金 |
| Claude の定額の契約（Claude Code） | 既に支払っている（追加の支払いは 0）。5 時間ごと・週ごとの利用枠がある | このセッションは定額の利用枠で動いており、追加利用（overage）は使っていない [実測: セッションの情報] |
| GitHub Actions（非公開リポジトリ） | 月の無料枠（プランにより 2,000〜3,000 分）の中なら 0 円 | v7 の無料の前処理 約 660 分 [実測] |
| Actions の成果物の保存 | 無料枠（プランにより 500 MB〜）の中なら 0 円。超えると新しい成果物を保存できなくなる（支払いの上限を設定していなければ課金はされない） | v7 の成果物 約 660 MB [実測]。過去の実行の成果物も 30 日残る |
| このクラウドの作業環境（Claude Code on the web） | 定額の契約に含まれる | — |

## 2. 全体設計（支払総額で比較）
| 設計 | 内容 | 実際の支払い（mid、幅） | 成果・品質 |
|---|---|---|---|
| A. API（今の既定） | 従量課金の API で読み取り・理解・統合 | 約 17,704 円（9,790〜30,510） | 今の基準 |
| A+. API＋候補 | 比較 P2（約 1,036 円）で合格した候補を使う | 約 14,639＋1,036＝約 15,675 円 | 比較で同等を確認した場合のみ |
| **B. Claude Code（G5）** | 同じ依頼をファイルで受け渡し、定額の契約の Claude Code（同じ claude-opus-5-5）が答える。答えは出力の形で検査 | **API 0 円＋比較 P-G5 約 1,500 円＝約 1,500 円**（−91.5%） | 比較で同等を確認するまで未検証（既定では使わない） |
| C. B と A の組み合わせ | 比較で同等と確認できた工程は B、できなかった工程は A | 約 1,500 円〜（A の一部） | 工程ごとに確認 |
| D. 他社の無料枠・手元の公開モデル | — | 0 円 | **不採用**（モデルの格下げ・品質の同等性を示せない） |

B は処理の回数・時間が多い（依頼 約 1,500 件、入力 約 3,400 万トークン、数十時間〜数日。利用枠の上限で待つことがある）が、
M26 の基準では支払いが最も安い。B の比較で不合格なら A に戻り、P-G5 の 約 1,500 円は無駄になる（最悪の場合 約 19,200 円）。

各設計の内部の最適化（M24・M25 のもの）はそのまま使える: 依頼の指紋による再利用（同じ依頼は 0 円・0 回）、
まとめ送り（B では待ちの回数が減る）、C5（B では出力が減り利用枠を節約）、段階を分けた比較。
A 固有のもの（Batch・キャッシュの先書き）は B では効かないが害もない。

## 3. 成果と品質の維持の検証（無料でできた範囲）
- B の仕組み: 依頼の書き出し・答えの検査・回答待ちでの停止と再開をテストで確認。答える側が同じ答えを返せば、意味理解の結果（指示の一覧）が
  直接答えた場合と同じになる（`tests/test_queue.py`）。回答待ちを失敗として扱うと結果が変わること（照合が「要確認」になる）をこのテストで見つけ、
  「状態を変えずに止める」に直した
- 読み取りの依頼を成果物から作れること: 事前説明1・PDF で 34 件を書き出し（AI には送っていない）
- **未検証**: Claude Code の答えが API と同じ品質か（画像が縮小されずに見えるか、会話の指示文の影響）→ P-G5 で確かめる

## 4. 承認をお願いすること（費用の安い順）
1. B を試すことの承認（資料を Claude Code で AI に送る。送り先は API と同じ Anthropic）と、P-G5（API 約 1,500 円）の承認
2. B が合格したら、B で全資料の本番（追加の支払い 0 円。利用枠の範囲で数日）
3. B が不合格なら A（または A+）

注意: Claude の契約で追加利用（overage）を有効にしている場合、B で利用枠を超えた分が課金される。無効にするか上限を設定してから行う。
Actions の成果物の保存が無料枠を超えると新しい成果物を保存できなくなるので、古い実行の成果物の削除（利用者の判断）を勧める。
