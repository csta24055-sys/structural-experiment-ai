# 資料の読み取り基盤（structlab read）

動画・PDF の内容を「取得・分割できた」で終わらせず、**書き起こし → 照合** まで行う層です。
指示の抽出・計算・提出物の作成より前の段階で、資料に何が書かれ・映り・話されているかを正確に残すことが目的です。

```bash
structlab read                         # 棚卸し＋ローカルの読み取り（無料）＋AIの見積もり
structlab read --only 事前説明1          # 一部の資料だけ（PDF は照合・用語のため常に読む）
structlab read --allow-external-ai     # Claude による画像の書き起こし・用語の訂正（有料。先に見積もりを確認）
```

結果は `work/reading/`（GitHub Actions では成果物 Artifacts、7日で削除）。元資料は読むだけで、Dropbox には書き込みません。

| ファイル | 内容 |
|---|---|
| `inventory.md` | 全ファイルの棚卸し（解析する資料／内容が同一の重複／補助ファイル／未対応） |
| `files/<資料>/reading.md` | ページ・場面ごとの書き起こし、OCR、発話、照合の結果 |
| `files/<資料>/frames/`, `pages/` | 場面の代表画面（資料の部分を切り出したもの）・ページ画像 |
| `summary.md` / `summary.json` | 資料ごとの状態（照合済み／要確認／未照合）と AI の見積もり・使用量 |

## 処理の流れ

1. **棚卸し**: 内容のハッシュが同じファイルだけを重複とし、代表（名前に「(1)」の無いもの）だけを読む。
   `.sh` などのスクリプトは資料ではない補助ファイルとして除く
2. **PDF（無料）**: テキスト層の文字を位置付きで取り出し、ページの回転を直して「見た目の行」にまとめる
   （表の見出しと値の対応を保つ）。図・写真・グラフのあるページを記録し、画像の中の文字は OCR しておく
3. **動画（無料）**:
   - 画面録画では、時計・アドレスバー・黒い余白を除いた**資料の領域を自動で切り出す**
   - 1秒ごとの画面の変化で**場面（スライド）に分割**。時計などの変化では区切らない。
     操作の画面録画（小さな変化が頻繁）は「操作」として記録し、カメラ撮影は一定間隔で区切る
   - 場面ごとの代表画面を高解像度で保存して OCR。同じ画面に戻った場面は「再表示」として結び付ける
   - 音声は large-v3-turbo で文字起こし（専門用語の手がかりとして PDF の用語を自動で与える）し、時刻で場面に割り当てる
4. **AI の書き起こし（許可時のみ・有料）**: PDF のページ・動画の場面ごとに、文字・表・数式（LaTeX）・図（軸・凡例・図中の文字）・
   写真の内容・操作を構造化して書き起こす。グラフから読んだ値は「概算」と明記させる。結果は保存し、同じ内容は再送しない
5. **文字起こしの用語の訂正（許可時のみ・有料・テキストのみ）**: 誤認識しやすい専門用語だけを直す。
   訂正後の語が資料（スライド・PDF）に無い訂正は採用しない。元の文字起こしは残す
6. **照合（無料）**:
   - PDF: テキスト層の行が書き起こしに含まれるか（取りこぼし）、書き起こしの数値がテキスト層・OCR にあるか（読み違い）
   - 動画: 場面の書き起こしを OCR と、PDF と同じ内容の場面は **PDF のテキスト層（正確な文字）** とも照合
   - 照合元が無いものは「未照合」。**未照合は成功ではない**

## 実際の資料での検証結果（2026-10-20、AI なし）

| 項目 | 結果 |
|---|---|
| 画面録画の資料領域 | 1170×2532 の縦長録画から 890×672 のスライド部分を検出（時計・URL・ツールバーを除外） |
| 場面の分割 | 15.6 分の講義動画を 8 場面に分割。区切りの時刻は発話の「まずこの絵を見て」等と一致 |
| OCR（切り出し前→後） | スライド1枚の主要な語句 16 件の一致度 0.24 → 0.76（切り出し＋拡大＋グレースケール＋疎な文字向け設定） |
| OCR（PDF のページで実測） | テキスト層を正解として文字の再現率 約 71〜75%。OCR だけでは不十分なため、AI の書き起こし＋照合が必要 |
| PDF の表 | 表の見出しと値が見た目どおりに対応（ページの回転を補正。以前は見出しが値の後に出ていた） |
| 文字起こし（6分間） | 専門用語の誤り: small 29 回 → large-v3-turbo＋用語の手がかり 5 回（梁→「針」、加力→「火力」等が解消） |

## 費用
`structlab read` を AI なしで実行すると、`summary.md` / `estimate.md` に必要な呼び出し回数と概算費用が出ます。
有料の実行（`--allow-external-ai`、GitHub Actions では `ops/requests/reading.txt` の `allow_external_ai: true`）は、
この見積もりを確認・承認してから行ってください。`reading.max_ai_calls` で1回の上限も決められます。
