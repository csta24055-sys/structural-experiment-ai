# 費用の構造と最適化（M23）

成果物と品質を変えないことを絶対条件に、費用を工程ごとに測り、内容が同じと確かめられた削減だけを採用する。
品質の同等性をまだ確かめていない削減は「候補」として既定で無効にし、小さな見本での比較（`structlab pilot`）に
通ったものだけを有効にする。有料AIの実行（本番・見本とも）は予算の承認後に限る。

## 費用の測り方

| 何を | どこで | 備考 |
|---|---|---|
| 読み取りの依頼の数・入力トークン | `summary_all.md`（`read --count-tokens`、無料の `count_tokens` API） | 画像・本文の入力は実測。出力は仮定 |
| 意味理解の依頼の数・入力 | `corpus/semantic_run/semantic_estimate.json` | 場面の数・文字数は実測 |
| 工程ごと・最適化ごとの円 | `corpus/costs/costs.json`（`structlab cost`） | low / mid / high の仮定は `costmodel.ASSUME` |
| GitHub Actions の利用時間 | 各実行の usage（private リポジトリは月の無料枠から差し引き） | 無料の前処理も含めて記録する |
| 最適化作業そのもの | 見本の比較（パイロット）の API 費用を `structlab pilot plan` に記載 | 承認後に実行 |

## 採用済み（内容が同じことを確認済み）

| 最適化 | 内容が同じと言える理由 | 効果 |
|---|---|---|
| Batch API | 同じ依頼・同じモデルで、届くのが遅いだけ | 入出力とも半額 |
| 指示の抽出の先頭部分のキャッシュ | 送る文字列は1文字も変えず、キャッシュの区切りを置くだけ | mid で約 375 円 |
| 実験区間・参照画像のキャッシュ | 同上 | — |
| 依頼の指紋（`request_hash`）による再利用 | 依頼の内容が完全に同じときだけ、保存した結果を使う | 再実行・中断後の再開で二重に払わない |
| 意味理解の DB を Actions のキャッシュに保存 | 読み取り結果の指紋（`reading_fingerprint`）が同じ資料だけ再利用 | 再実行時の意味理解の再送をなくす |
| 役割ごとのキャッシュ鍵（`role_key`） | 設定を変えた役割の資料だけ読み直す | 無料の前処理の時間と、変わっていない資料の AI 費用 |
| キャッシュの有効期間は 5 分のまま | 1 時間にすると書き込みが 2 倍で、見積もりでは高くなった | — |

## 候補（品質の比較が必要。既定は無効）

| ID | 内容 | 見込める削減（mid） | 見本 |
|---|---|---|---|
| C1 | 資料全体の理解を依頼の先頭に置いてキャッシュ（順序だけ変わる） | 約 520 円 | 事前説明1 の意味理解の全段階 |
| C2 | 意味理解に渡す材料を短い書き方に（キー・値は全部残す） | 約 105 円 | 同上 |
| C4 | 照合を同じ場面で最大5件まとめる | 約 1,474 円 | エクセルの作り方1 の照合（約30件） |
| C3 | （逆方向）実験区間を4つずつ読む今の構成が、区間ごとと同等か | 同等でなければ費用は増える | 先生2 の 8 区間 |

採用の条件（`structlab pilot compare`）: 今の方式をもう一度実行したもの（repeat）を揺れの基準にし、
候補の包含率 ≥ repeat の包含率 − 0.02、かつ重要項目（禁止・必須・条件付きの指示、数値、セル番地、数式、設定）の
欠落が repeat 以下のときだけ採用する。満たさなければ今の方式のまま。

## 採用しなかったもの

| 案 | 理由 |
|---|---|
| モデルの格下げ・段階的な切り替え | 指示（M16・M23）で禁止 |
| 実験区間を 15 秒あたり 2 枚に | M20 で 3 枚に戻す指示 |
| 画面を縮小して送る | 細部（セル・数式）の読み取りが落ちる。M21 で最高品質を指示 |
| 1 時間のキャッシュ | 書き込みが 2 倍で、Batch の中では読み出しが保証されず高くなる |
| 照合・再解釈の回数を減らす | 出力（照合の結果）が減る |

## 未検証の項目

- 出力の量（AI が書く量・思考の量）は実測できないので幅で示す（low / mid / high）
- Batch の中でキャッシュが読まれる割合は保証されない（0.3〜0.9 と仮定）
- P085（実験区間をまとめて読む構成と区間ごとの同等性）は C3 の見本で確かめるまで未解決
