# 各工程のチェックと独立した再検証

既存の処理（抽出 → 意味理解 → 指示抽出 → 照合 → 統合）の順序と仕組みは変えず、各工程が終わった直後に
「その工程で不足していた検査」だけを追加しています。結果は `checks` テーブルと `results/checks/checks.md` に出ます。
実装: `src/structlab/checks/`

## 状態の区別

| 状態 | 意味 |
|---|---|
| 成功 (ok) | 照合して一致した |
| 不一致 (mismatch) | 照合して食い違った |
| 要確認 (needs_review) | 機械的には判断できない疑いがある |
| 未検証 (unverified) | 照合の材料・手段がない（**成功ではない**） |
| チェック不能 (failed) | チェック自体が実行できなかった |

## 既存の検証（変更なし）と、追加したチェック

| 工程 | 既にあった検証 | 追加したチェック |
|---|---|---|
| 資料抽出 | ダウンロード時の内容照合、アップロード途中の除外、ZIPの安全性、スキャンページの判定 | 音声と映像の時刻対応（発話が区間内か・発話時点で表示済みの画面を対応付けているか）、文字起こし（未実施・発話ゼロ・低信頼）、OCR（文字化けの疑い・OCRなし）、数値の誤読の疑い（英字のO/l/Iの混入）、数式の括弧の対応、**Excelの全数式の再計算**（保存値との照合・エラー値・空セル参照）、読み取り失敗 |
| 局所理解・全体理解 | （第3回照合は指示が対象） | 場面の要点の時刻・訂正等の根拠が原文にあるか、全体理解の場面番号・手順番号の参照、訂正・補足・整合説明の根拠、規則が原文から見つけた訂正と全体理解の訂正の一致、相互照合の収束、失敗場面を含まない全体理解の警告 |
| 指示抽出 | 根拠の照合、分類の向き・強さの検査、見落とし候補、第3回照合、訂正・矛盾の関連付け | **発言者**（話者識別をしていないので音声の指示は「発言者未確認」。先生と断定しない）、対象作業の欠落、条件付き指示の条件の欠落、既存の照合状態の集計 |
| 複数資料の統合 | 値の食い違い（提出期限・形式等）、資料間の向きが逆の指示 | **数値の照合**（「断面積は78.5 mm2」等を資料間・Excelの定数と照合）、提出条件の一致、統合理解の手順が実在する資料を根拠にしているか |
| 将来のExcel・レポート | なし | 下書きの検査（提出物は作らない）: Excelの再計算・列見出しの単位・散布図/近似曲線/凡例/軸タイトルと指示の照合、文章中の数値が元資料・計算で確認できるか・単位の欠落・必要な章・提出形式/ページ数、必須/禁止/条件付き指示の確認リスト（自動判定せず「未検証」） |

### Excel の再計算について
- Excel が保存した計算結果を使わず、入力値から数式を計算し直して照合します（参照先の数式も入力値から計算し直す）
- 対応関数: 四則演算・べき乗・%・SUM/AVERAGE/MIN/MAX/COUNT/PRODUCT/MEDIAN/STDEV/VAR/ABS/SQRT/POWER/EXP/LN/LOG/ROUND系/SLOPE/INTERCEPT/IF/三角関数 など。
  対応していない関数（VLOOKUP など）は「未検証」として記録し、成功にしません
- Excel で一度も保存されていない（計算結果が保存されていない）ブックは照合できないため「未検証」になります

## 独立した再検証（`structlab reverify`）

工程内のチェックとは別に、すでに出ている結論を正解として扱わずに確認し直します。
1. 対象の優先順位: 要確認・不一致・見落とし候補 → 必須・禁止・条件付き → 確実性が低いもの
2. 規則による再抽出（常に・無料）: 元の発話・画面・資料の該当範囲だけから、言い回しで指示を拾い直す
3. AIによる盲検の再抽出（`--allow-external-ai` のときだけ・有料）: 最初の解釈・全体理解・対象の指示を見せず、元の範囲だけを渡して指示を列挙させる
4. 突き合わせ: 分類・条件が一致するか。食い違いは「修正案（未適用）」として修正前後と理由を `revisions` に保存し、自動では書き換えません
5. どちらの再抽出でも確認できないもの（例: AIの推論による指示）は「未検証」のまま
6. 同じ入力で再検証済みのものは繰り返しません

数値・数式は、抽出工程の Excel 再計算と統合工程の数値照合で毎回プログラムが計算・照合しています（同じ処理を再検証で重複させない）。

## コマンド

```bash
structlab checks                       # 工程別の集計と checks.md の生成
structlab reverify                     # 独立した再検証（規則のみ・無料）
structlab reverify --allow-external-ai # AIによる盲検の再抽出も行う（有料。事前に承認を得ること）
structlab check-draft 下書き.md --format PDF   # 下書きの検査（提出物は作らない）
structlab check-draft 下書き.xlsx
```
