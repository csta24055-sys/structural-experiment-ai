## 2. P-G5 の判定（許容差の撤廃）
- 合格の条件: 種類ごとに **G5 の包含率 ≥ API どうしの包含率**（0.02 の許容差を撤廃。小数の計算誤差 1e-9 だけ吸収）、
  重要項目（数値・セル番地・数式・設定・禁止/必須/条件付きの指示・照合の判定）の欠落 ≤ API どうし、読めない件数 ≤ API の 1.25 倍＋1
- 費用（約 1,000 円）・方式（API 2 回＋G5 1 回、約 32 件）は変えない。費用削減の候補の判定（`structlab pilot compare`）の既定も同じく許容差 0 にした
- 試験: 同じなら合格、わずかに下回れば不合格（以前の基準では合格）、重要項目を多く落とせば不合格（`tests/test_queue.py`・`tests/test_pilot.py`）

## 3. 作業フォルダの保全（`docs/G5_BACKUP.md`）
- 選択: Dropbox の解析結果フォルダに、作り直せないもの（答え・P-G5 の結果・印）だけを、追加だけで保存。復元は sha256 で検査し、手元を上書きしない
- 無料の試験: 単体（7 件）と、全 9 資料の試験用フォルダでの実地の復旧（保存 → 新しいフォルダに作り直し → 復元 → 完走）
- 有効にするには、書き込みの許可のあるトークンの受け渡しが必要（利用者の判断。G5_BACKUP.md §5）
