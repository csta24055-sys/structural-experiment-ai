## (1) 計算過程（用紙(1)の〈計算過程〉欄）

**① 品質基準強度 Fq**

講義スライド「調合管理強度と調合強度」で Fm = Fq + mSn の Fq は「コンクリートの**品質基準強度**」と定義されている（設計基準強度ではない）。
品質基準強度は、設計基準強度 Fc と耐久設計基準強度 Fd の大きい方とする（JASS 5）。

- 設計基準強度：Fc = 27 N/mm²
- 計画供用期間の級「長期」→ 耐久設計基準強度：Fd = 30 N/mm²
  （JASS 5：短期 18、標準 24、長期 30、超長期 36 N/mm²）

  Fq = max(Fc, Fd) = max(27, 30) = **30 N/mm²**

**② 構造体強度補正値 28S91**

普通ポルトランドセメント、工事時期 10月1日 → 表の「9/12〜12/7（8 ≦ θ ≦ 25）」の区分に入る。

  28S91 = **3 N/mm²**（≧ 0 を満たす。材齢 m = 28 日、n = 91 日）

**③ 調合管理強度 Fm**

  Fm = Fq + 28S91 = 30 + 3 = **33 N/mm²**

**④ 調合強度 F**（σ = 2.5 N/mm²、次の2式を両方満足させる）

  F ≧ Fm + 1.73σ = 33 + 1.73 × 2.5 = 33 + 4.325 = 37.325 N/mm²

  F ≧ 0.85Fm + 3σ = 0.85 × 33 + 3 × 2.5 = 28.05 + 7.5 = 35.55 N/mm²

  両方を満たすには大きい方：F ≧ 37.325 N/mm²
  小数点以下切り上げ → **F = 38 N/mm²**

## (2) 計算過程（用紙(2)の〈計算過程〉欄）

**① セメント水比・水セメント比**（図の横軸は C/W であることに注意）

  f = 26 (C/W) − 14 に f = F = 38 N/mm² を代入
  38 = 26 (C/W) − 14 → C/W = (38 + 14) / 26 = 52 / 26 = 2.00
  W/C = 1 / (C/W) = 1 / 2.00 = 0.500 → **水セメント比 50.0 %**

**② 単位セメント量**

  C = W ÷ (W/C) = 170 ÷ 0.500 = **340 kg/m³**

**③ 各材料の絶対容積**（1 m³ = 1000 ℓ、密度 g/cm³ = kg/ℓ）

| 材料 | 計算 | 絶対容積 |
|---|---|---:|
| 水 | 170 kg ÷ 1.00 kg/ℓ | 170 ℓ |
| 空気 | 1000 × 4.5/100 | 45 ℓ |
| セメント | 340 ÷ 3.15 = 107.94 | **108 ℓ** |
| 粗骨材 | 0.60 m³/m³ × 60.0 % × 1000/100 | **360 ℓ** |
| 細骨材 | 1000 − (170 + 45 + 107.94 + 360) = 317.06 | **317 ℓ** |

**④ 骨材の単位量**（単位量 = 絶対容積 × 密度）

  細骨材 S = 317.06 × 2.65 = 840.22 → **840 kg/m³**
  粗骨材 G = 360 × 2.70 = **972 kg/m³**

**⑤ 細骨材率**

  s/a = Vs / (Vs + Vg) × 100 = 317.06 / (317.06 + 360) × 100 = 317.06 / 677.06 × 100 = 46.83 → **46.8 %**

**⑥ 調合上の単位容積質量**（空気は質量 0）

  W + C + S + G = 170 + 340 + 840 + 972 = **2322 kg/m³**
  （丸めずに計算しても 170 + 340 + 840.22 + 972 = 2322.22 → 2322 kg/m³）

**検算**：容積の合計 170 + 45 + 107.94 + 317.06 + 360 = 1000.00 ℓ ✓、
26 × 2.00 − 14 = 38 N/mm² ✓

## 端数処理と差異の確認

- 内部計算は丸めず保持し、回答欄の値だけ丸めた（最終丸め）。調合強度は切り上げ、W/C・s/a は小数第1位四捨五入、その他は整数四捨五入。
- 比較として「途中丸め」（Vc を 108 ℓ に丸めてから Vs = 1000 − 170 − 45 − 108 − 360 = 317 ℓ、S = 317 × 2.65 = 840.05 → 840、s/a = 317/677 = 46.82 → 46.8）でも計算したが、**全欄で最終丸めと一致**し、差異はない（テスト `test_answer_table_intermediate_rounding_agrees`）。
- C/W = 2.00 がちょうど割り切れるため、W/C・C には丸め誤差が生じない。

## 注記：Fq の解釈について（要確認点）

`PROBLEM.md` の転記では「設計基準強度 Fq = 27」と書かれていたが、問題用紙原本には記号 Fq は無く「設計基準強度：27 N/mm²」とだけある。講義スライドは Fq を「品質基準強度」と定義しており、問題文がわざわざ「計画供用期間の級：長期」を与えているのはこの条件（Fd = 30）を使わせるためと判断した。さらに Fq = 30 とすると (2) で C/W = 2.00 とちょうど割り切れるため、出題意図とも整合する。

参考として、もし Fq = Fc = 27 とした場合（計画供用期間の級を使わない解釈）の値は：
Fm = 30、F = ceil(34.325) = 35、W/C = 53.1 %、s/a = 47.3 %、C = 320、S = 857、G = 972、Vc = 102、Vs = 323、Vg = 360、単位容積質量 2319 kg/m³（この場合は途中丸めだと S = 856、質量 2318 となり差異が出る）。
講義で Fd を扱っていない等の事情があれば担当教員に確認すること。
