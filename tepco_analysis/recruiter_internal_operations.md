## 5. 再構成した内部フロー

```
[i-web マイページ登録] ──大学・学科で振り分け [推定・強]
      │
      ▼
[大学別リクルーターの定型案内] [確認]
      │   個別相談・面談（評価ステップではない [証言]）
      │   └→ 所見の人事への共有 ？[不明]
      ▼
[インターン応募：ES・履歴書] ← 現在ここの直前
      │   書類選考（応募多数時）── 人事 [確認]
      ▼
[冬期インターン参加（建築30名）]
      │   参加中の評価 ？[不明]
      ▼
[早期選考の案内（電話等）] ── 人事 [証言：技術系。建築は未確認]
      │   面接（人事＋部門の部長）[証言]
      ▼
[内々定]

  別経路：インターン不参加 → 本選考（3/1〜）→ 面接 → 内定 [確認：27卒]
  並行：部門人事担当への直接連絡（チラシで公開）[確認]
```

## 6. 現在の位置

- **位置**：「マイページ登録・リクルーター接触済み、インターン応募の直前」。
- 優遇選考への分岐として**確認できる唯一の入口（インターン参加）**には、まだ入っていない。
- 前根氏（建築部門人事担当）と自分から連絡を取っていることは、**人事部門に応募者として認識されている可能性**を高める[推定]。ただし、これは評価や推薦とは別のことで、この接点が選考に影響するという証拠はない。
- 吉川氏が人事へ何を伝えているか（または何も伝えていないか）は[不明]で、外部から確認する手段はない。
- **結論**：内部フロー上の分岐を決める次の変数は、リクルーターの意思ではなく、**11/8までに応募するか（＋どのコースか）**である。技術系の証言から見て、優遇（早期選考）が付く主な経路はインターン参加の後にある。
