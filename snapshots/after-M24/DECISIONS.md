## 3b. M24 の判断
| 判断 | 理由 |
|---|---|
| 先書きは 6 件以上のまとまりだけ | 1 時間の書き込みは 2 倍。件数が少ないと読み出しの節約を上回る（費用モデルで試算） |
| まとめ送りは Batch の門がある経路だけ | 1 件ずつの経路では中断時に受け取った結果を失い、時間の上限の確認も遅れる（検証チームの指摘） |
| 比較は候補が影響する段階だけ | 全工程の比較は 1 候補 約 2,000 円で、本番 1 回の削減を上回るため |
| C2（短い書き方）は比較しない | 削減 約 110 円に対し比較 約 2,080 円 |
| D1（Excel の全体画面を元の解像度に）は採用しない | M21 の「費用が増えても最高品質」を優先。利用者の判断で比較できるように記録 |
| effort を下げない・モデルを変えない | M16・M23・M24 |

| 案 | 理由 |
|---|---|
| モデルの格下げ・安いモデルでの下読み | M16・M23 で禁止 |
| 実験区間 2 枚 | M20 で 3 枚に戻す指示 |

| 照合・再解釈の回数を減らす、effort を下げる | 成果・品質が減る |
