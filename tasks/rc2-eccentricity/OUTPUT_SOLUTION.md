## 0. 条件の整理

| 項目 | 内容 |
|---|---|
| 平面 | X方向 12 m（6 m＋6 m）、Y方向 8 m、原点は左下 |
| 柱 | 下段 y=0 m・上段 y=8 m に、それぞれ x=0, 6, 12 m の計6本 |
| 鉛直荷重 N | 上段・下段とも左から 100, 200, 100 kN（合計 800 kN） |
| X方向剛性 | 6本の柱すべて KX = K（「X方向入力に対しては柱のみ抵抗」） |
| Y方向剛性 | x=0, 6 の柱4本は KY = K。右端 x=12 m は **耐震壁（柱＋壁）で KY = 8K** |

### 右端の耐震壁 KY=8K の解釈

課題文の「耐震壁（**柱＋壁**）の水平剛性：KY=8K」は、右端の両端柱と壁を一体とした
**等価ばね1個の剛性**と解釈します。したがって

- **Y方向**：x=12 m の位置に 8K を **1回だけ** 置く（端柱の K をさらに2本足さない）。
- **X方向**：壁は面外なので抵抗しない。右端の2本も普通の柱として **各 K** を数える。

二重計上（8K＋K＋K＝10K）した場合の誤差は §8 の感度解析に示します。

### X・Y の対応（取り違え防止）

| 求めるもの | 使う剛性 | 理由 |
|---|---|---|
| 剛心の x 座標 RX | **KY**（Y方向剛性） | Y方向の力に抵抗する要素が「x方向のどこにあるか」 |
| 剛心の y 座標 RY | **KX**（X方向剛性） | X方向の力に抵抗する要素が「y方向のどこにあるか」 |
| X方向の偏心率 ReX | eY / reX | X方向加力では y 方向のずれ eY がねじりを生む |
| Y方向の偏心率 ReY | eX / reY | Y方向加力では x 方向のずれ eX がねじりを生む |

K は基準剛性（記号）として残し、数値を代入しません。

## 1. 重心の算定

$$G_X=\frac{\Sigma(N\cdot X)}{\Sigma N},\qquad G_Y=\frac{\Sigma(N\cdot Y)}{\Sigma N}$$

ΣN = (100 + 200 + 100) + (100 + 200 + 100) = **800 kN**

Σ(N·X) = 100×0 + 200×6 + 100×12 + 100×0 + 200×6 + 100×12
　　　 = 0 + 1200 + 1200 + 0 + 1200 + 1200 = 4800 kN·m

Σ(N·Y) = (100 + 200 + 100)×0 + (100 + 200 + 100)×8 = 0 + 3200 = 3200 kN·m

$$G_X=\frac{4800\ \text{kN·m}}{800\ \text{kN}}=\mathbf{6.0\ m},\qquad
G_Y=\frac{3200\ \text{kN·m}}{800\ \text{kN}}=\mathbf{4.0\ m}$$

→ 図中の G = (6 m, 4 m) と一致。

## 2. 剛心の算定

$$R_X=\frac{\Sigma(K_Y\cdot X)}{\Sigma K_Y},\qquad R_Y=\frac{\Sigma(K_X\cdot Y)}{\Sigma K_X}$$

**RX（Y方向剛性 KY を使う）**

| 位置 | KY | x [m] | KY·x |
|---|---|---|---|
| x=0 の柱2本 | K＋K＝2K | 0 | 0 |
| x=6 の柱2本 | K＋K＝2K | 6 | 12K |
| x=12 耐震壁（柱＋壁） | 8K | 12 | 96K |
| 合計 | **ΣKY＝12K** | | **108K m** |

$$R_X=\frac{2K\times0+2K\times6+8K\times12}{2K+2K+8K}=\frac{108K\ \text{m}}{12K}=\mathbf{9.0\ m}$$

**RY（X方向剛性 KX を使う）**

| 位置 | KX | y [m] | KX·y |
|---|---|---|---|
| y=0 の柱3本 | 3K | 0 | 0 |
| y=8 の柱3本 | 3K | 8 | 24K |
| 合計 | **ΣKX＝6K** | | **24K m** |

$$R_Y=\frac{3K\times0+3K\times8}{3K+3K}=\frac{24K\ \text{m}}{6K}=\mathbf{4.0\ m}$$

→ 剛心 **R = (9.0 m, 4.0 m)**。剛性の大きい耐震壁側（右）へ重心から寄る（図の赤点の位置と整合）。

## 3. 偏心距離の算定

$$e_X=|R_X-G_X|=|9.0-6.0|=\mathbf{3.0\ m}$$
$$e_Y=|R_Y-G_Y|=|4.0-4.0|=\mathbf{0\ m}$$

## 4. ねじり剛性の算定

$$K_R=\Sigma\{K_X\,(Y-R_Y)^2\}+\Sigma\{K_Y\,(X-R_X)^2\}$$

**KX の項**（RY = 4 m からの距離）

- y=0 の柱3本：3K × (0 − 4)² = 3K × 16 = 48K m²
- y=8 の柱3本：3K × (8 − 4)² = 3K × 16 = 48K m²
- 小計　Σ{KX(Y−RY)²} = 48K + 48K = **96K m²**

**KY の項**（RX = 9 m からの距離）

- x=0 の柱2本：2K × (0 − 9)² = 2K × 81 = 162K m²
- x=6 の柱2本：2K × (6 − 9)² = 2K × 9 = 18K m²
- x=12 耐震壁：8K × (12 − 9)² = 8K × 9 = 72K m²
- 小計　Σ{KY(X−RX)²} = 162K + 18K + 72K = **252K m²**

$$K_R=96K+252K=\mathbf{348K\ m^2}$$

（耐震壁は KY のみを持つので、KX 項には現れない。壁の y 座標をどこに置いても KR は変わらない。）

## 5. 弾力半径の算定

$$r_{eX}=\sqrt{\frac{K_R}{\Sigma K_X}}=\sqrt{\frac{348K\ \text{m}^2}{6K}}=\sqrt{58\ \text{m}^2}=\mathbf{7.62\ m}\ (7.6158)$$

$$r_{eY}=\sqrt{\frac{K_R}{\Sigma K_Y}}=\sqrt{\frac{348K\ \text{m}^2}{12K}}=\sqrt{29\ \text{m}^2}=\mathbf{5.39\ m}\ (5.3852)$$

K は分子・分母で約分され、弾力半径は長さ [m] になる。

## 6. 偏心率の算定

$$R_{eX}=\frac{e_Y}{r_{eX}}=\frac{0\ \text{m}}{7.62\ \text{m}}=\mathbf{0}\quad\le 0.15\ \ \text{OK}$$

$$R_{eY}=\frac{e_X}{r_{eY}}=\frac{3.0\ \text{m}}{5.39\ \text{m}}=\mathbf{0.557}\ (0.5571)\quad> 0.15\ \ \text{NG}$$

## 結論

| | X方向 | Y方向 |
|---|---|---|
| 偏心距離 | eY = 0 m | eX = 3.0 m |
| 弾力半径 | reX = 7.62 m | reY = 5.39 m |
| 偏心率 | **ReX = 0** | **ReY = 0.557** |
| 判定（0.15） | 満足 | **超過** |

**Y方向の偏心率 ReY = 0.557 が講義の目安 0.15 を超える。** 右端だけに剛性の大きい
耐震壁（8K）があり、剛心が重心から 3 m 右へずれているため、Y方向の地震力に対して
大きなねじれが生じる。講義ノート13ページにある通り、偏心率が 0.15 を超える場合は
形状係数 Fe による必要保有水平耐力の割増しを検討する必要がある
（改善には左端にも耐震壁を配置するなど、剛性をバランスさせる）。

## 7. 独立検算（別方式：剛床の剛性マトリクス法） — `independent_check.py`

`solver.py` を使わずに、入力を「部材リスト」として別に入力し直し、剛床の
3自由度（u, v, θ）剛性マトリクスを原点まわりに組み立てた。

- Kuu = ΣKX = 6K、Kvv = ΣKY = 12K
- Kuθ = −Σ KX·y = −24K m、Kvθ = Σ KY·x = 108K m
- Kθθ（原点まわり）= Σ KX·y² + Σ KY·x² = 3K×8² + (2K×6² + 8K×12²) = 192K + 1224K = 1416K m²

連成項が消える点として剛心：RX = Kvθ/Kvv = 108/12 = 9 m、RY = −Kuθ/Kuu = 24/6 = 4 m

平行軸の定理で剛心まわりへ移す：
KR = 1416K − (−24K)²/6K − (108K)²/12K = 1416K − 96K − 972K = **348K m²**（一致）

さらに重心 G に単位力 PY = 1 を作用させて K·d = f を数値的に解くと、
床の回転角 θ = −0.0086207/K、|θ|·KR = 3.000 m = eX となり、
偏心距離とねじり剛性の組合せが変位解析からも確認できた（X方向加力では θ = 0）。

## 8. 感度解析（解釈・取り違えの影響）

| ケース | ΣKX | ΣKY | RX [m] | KR [K m²] | ReY |
|---|---|---|---|---|---|
| **正：壁8Kを1回、X方向は柱6本** | 6K | 12K | 9.000 | 348.0 | **0.557** |
| 誤(a)：壁8K＋端柱KY 2本を二重計上 | 6K | 14K | 9.429 | 363.4 | 0.673 |
| 誤(b)：X/Y取り違え（KXとKYを入替） | 12K | 6K | 6.000 | 208.0 | 0（判定が逆転） |
| 誤(c)：壁がX方向にも8K抵抗 | 14K | 12K | 9.000 | 348.0 | 0.557 |
| 確認：壁のy座標を0 m／8 mにしても | 6K | 12K | 9.000 | 348.0 | 0.557 |
| 誤(e)：講義例題（右下柱3K）を流用 | 6K | 8K | 7.500 | 294.0 | 0.247 |

- 二重計上すると ReY が約2割大きく出る。
- X/Y を取り違えると「偏心なし」と誤判定してしまうため、最も危険な誤り。
- 誤(c)は ReY を変えないが ΣKX と reX を変えてしまうので、注記どおり壁のX方向剛性は入れない。
