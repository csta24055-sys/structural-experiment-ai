鉄筋コンクリート構造Ⅱ　偏心率の算定　解説

図は課題図の転記値（PROBLEM.md）から作成した模式図。講義ノート pp.20–22 の手順（重心→剛心→偏心距離→ねじり剛性→弾力半径→偏心率）に従う。 Kは基準剛性として記号のまま扱う。

0. モデル化の要点

  • 右端の耐震壁（柱＋壁）KY＝8Kは、端柱2本と壁をまとめた1つの等価ばね。Y方向では x＝12 m に8Kを1回だけ置き、端柱のKを足さない。
  • 「X方向入力に対しては柱のみ抵抗」→ X方向は柱6本が各K（ΣKX＝6K）。壁はX方向剛性を持たない。
  • RX には KY、RY には KX を使う。ReX＝eY/reX、ReY＝eX/reY（加力方向と直交する偏心がねじりを生む）。

1. 重心

ΣN = 100+200+100+100+200+100 = 800 kN GX = Σ(N·X)/ΣN = (100×0 + 200×6 + 100×12 + 100×0 + 200×6 + 100×12)/800 = 4800/800 = 6.0 m GY = Σ(N·Y)/ΣN = {(100+200+100)×0 + (100+200+100)×8}/800 = 3200/800 = 4.0 m

2. 剛心

RX = Σ(KY·X)/ΣKY = (2K×0 + 2K×6 + 8K×12)/(2K + 2K + 8K) = 108K/12K = 9.0 m RY = Σ(KX·Y)/ΣKX = (3K×0 + 3K×8)/(3K + 3K) = 24K/6K = 4.0 m

剛心は剛性の大きい耐震壁側へ寄り、R＝(9.0, 4.0) m。

3. 偏心距離

eX = |RX − GX| = |9.0 − 6.0| = 3.0 m eY = |RY − GY| = |4.0 − 4.0| = 0 m

4. ねじり剛性

Σ{KX(Y−RY)²} = 3K×(0−4)² + 3K×(8−4)² = 48K + 48K = 96K m² Σ{KY(X−RX)²} = 2K×(0−9)² + 2K×(6−9)² + 8K×(12−9)² = 162K + 18K + 72K = 252K m² KR = 96K + 252K = 348K m²

5. 弾力半径

reX = √(KR/ΣKX) = √(348K/6K) = √58 = 7.62 m reY = √(KR/ΣKY) = √(348K/12K) = √29 = 5.39 m

6. 偏心率

ReX = eY/reX = 0/7.62 = 0 ≦ 0.15　OK ReY = eX/reY = 3.0/5.39 = 0.557 ＞ 0.15　NG

Y方向の偏心率 ReY＝0.557 が 0.15 を超える。右端だけに剛な耐震壁があるため剛心が重心から3 m右へずれ、 Y方向の地震力に対して床が大きくねじれる。講義ノートp.13のとおり、0.15超では形状係数Feによる必要保有水平耐力の割増しを検討する （左端にも耐震壁を設けるなど、剛性配置の均衡で改善できる）。

7. 独立検算（剛床の剛性マトリクス法）

原点まわり：Kuu=ΣKX=6K、Kvv=ΣKY=12K、Kuθ=−ΣKX·y=−24K m、Kvθ=ΣKY·x=108K m Kθθ = ΣKX·y² + ΣKY·x² = 3K×8² + (2K×6² + 8K×12²) = 192K + 1224K = 1416K m² RX = Kvθ/Kvv = 108/12 = 9 m、RY = −Kuθ/Kuu = 24/6 = 4 m KR = 1416K − (24K)²/6K − (108K)²/12K = 1416K − 96K − 972K = 348K m² （一致） G に PY=1 を与えて K·d=f を解く → |θ|·KR = 3.000 m = eX （一致）
